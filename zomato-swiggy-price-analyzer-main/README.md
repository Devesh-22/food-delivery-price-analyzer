
# 🍔 Zomato & Swiggy Price Analyzer

A data-driven web application that compares food prices across Zomato and Swiggy platforms and helps users identify the cheapest option using interactive visualizations.

This project compares food prices across Zomato and Swiggy.


## 📂 Project Structure

```
zomato-swiggy-price-analyzer/
│
├── app.py
├── README.md
├── requirements.txt
└── data/
    └── food_prices.csv
```

---

## 🚀 Features
- Select food items using a dropdown
- Compare minimum prices on Zomato and Swiggy
- Identify the cheaper platform and price difference
- Restaurant-wise price comparison
- Average price analysis with insights
- Interactive bar charts for visual comparison

---

## 🛠 Tech Stack
- Python
- Pandas
- Streamlit
- Matplotlib

## How to run
1. Install libraries
pip install streamlit pandas matplotlib

2. Run the app
python -m streamlit run app.py


📊 Dataset

The dataset contains food prices from Zomato and Swiggy with the following columns:

platform
restaurant
item
price
